# 服装打版图的制图规范(做「自动出打版图」技能的依据)

> 2026-09-19 调研整理。**主依据:GB/T 29863-2023《服装制图》**(2024-03-01 实施,代替 2013 版)。
> 全文未拿到官方版,依据是 bzxz.net 的 OCR 预览(个别行有乱码,下文标了推断处)。
> 元数据:https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=1D14053761105968EA7436F87327DC81

## 一、线型(GB/T 29863-2023 表 2)

| 线型 | 用途 |
|---|---|
| 粗实线 | 服装和零部件轮廓线、部位轮廓线 |
| 细实线 | 基础线、尺寸线和尺寸界线、引出线 |
| 粗虚线(OCR 丢了行名,据前言推断) | 背面或下层部件轮廓(如贴边)、对称裁剪线 |
| 细虚线 | 缝纫明线、等分线 |
| 点划线 | 对折线、折转线(首尾必须是画,不能是点) |

细线 0.1–0.5 mm,粗线是细线的 1.5–2.5 倍;同一张图同类线等宽。2013 版的「双点划线」2023 版并入点划线。
**净样 / 毛样标准没点名**:行业惯例是裁剪样板的外圈粗实线为毛样(含缝份),内圈细线为净样。

## 二、符号(表 3)

布纹线(经向):双箭头 = 无方向;单箭头 = 有倒顺(绒毛 / 单向花)。对位记号(剪口):垂直于缝边、深约 0.5 cm;
**一个剪口 = 前,两个(间距 1 cm)= 后**。褶裥:斜线表示,从高端折向低端;顺褶与工字褶画法不同。
省道:可带倒向箭头;钻眼在省尖内 1–2 cm。等分线、直角、重叠、拼合、敷衬(三条斜线)、归拢 / 拔开、扣位扣眼等也在表 3。
**标准外的符号必须在图上用图 + 文字说明**(6.3 条)。

## 三、每片必须标注

款号、裁片名称、面 / 里 / 衬、裁片数量(成对 ×2;单片 ×1,一侧用 ×1 左 / ×1 右)、号型、布纹线。
缝份:平缝 1 cm(0.8–1.2),包缝 0.6,下摆 / 袖口 3–4,拉链 / 袋口 1.5–2;汉服下摆 2–3,有袖缘时袖口 1。

## 四、尺寸标注(第 5 章)

单位 cm 不写;每个尺寸只标一次;数值可以是数字、公式(B/4+2、W−2B)或 △○ 记号;
尺寸线细实线、带箭头,不许压在结构线上;大尺寸在外、小尺寸在内。部位代号:B W H N S L SL BL WL HL…
(2023 版改了部分代号,附录 D 没读到,**别硬编新代号**)。

## 五、汉服结构

- **十字型平面结构**:无肩缝(肩线是对折线,点划线)、前后连裁、有后中缝;
  交领有「接衽」和前中缝,对襟 / 直领没有;**接袖**由布幅(约 50 cm)决定。
  主尺寸:横轴通袖长、纵轴衣长。常画半片,在后中对折。
- **马面裙**:两片长方裙片,每片两端是裙门(马面)、中间打褶;一条裙腰带系带;穿着时前后裙门两两重叠。
  腰围 = 净腰 + 4–8;裙门 20–24;褶总宽 = W − 2×裙门;裙腰长 ≈ W + 一个裙门的搭叠量。
  ⚠️ 来源公式不一致(另一种:褶距 A=(W−3B)/4,展开宽 = 2B+4A+12C),褶的倒向没找到统一说法 —— **不硬编**。
- 褙子:直领对襟,领缘通到底,两侧开衩到腋下。圆领袍:大襟圆领、小襟直领,两侧外摆,接袖。

## 六、图框与排料

图幅按 GB/T 14689;比例 1:1 / 1:2 / 1:5 / 1:10,一张图一个比例写在标题栏;
标题栏(右下):款号款名、号型、规格表、比例、制图人、日期、复核(后两项是建议,非标准条文)。
单片纸样:布纹线竖直放。排料图常用 1:10,要写门幅、用料长度、经纬向。

## 七、自检清单(生成的打版图必须有)

1. 线型按角色(轮廓粗实 / 基础与尺寸细实 / 下层粗虚 / 明线等分细虚 / 对折点划)
2. 净样与毛样都画,缝份按边给(默认 1,下摆袖口 2–4)
3. 每片有布纹线,单片视图里竖直
4. 对折边画点划线并标「对折」,对折边不加缝份
5. 剪口垂直于边;前一个、后两个;相缝合的边剪口对得上
6. 褶裥用斜线表示倒向
7. 每片标:款号、裁片名、面料、数量、号型
8. 尺寸 cm 不写单位,可写公式,箭头尺寸线不压结构线、只标一次
9. 右下标题栏:款号、号型、规格表、比例、制图人、日期
10. 汉服:无肩缝(肩线对折)、后中缝、交领才有接衽、接袖按布幅
11. 用了标准外的符号要有图例
