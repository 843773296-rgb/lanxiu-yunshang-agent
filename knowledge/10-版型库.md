# 版型库

⚠️ 本文件为 `demo` 演示数据,**所有裁片数与成衣尺寸须由版师确认后替换**。

## 零、版型不是款式

这两个词在门店里天天混着用,但它们是两样东西,分开存才管得住:

| | 款式(style) | 版型(pattern) |
|---|---|---|
| 回答什么 | **长什么样** —— 交领还是对襟、什么颜色、绣什么 | **怎么裁** —— 分几个裁片、每片多大 |
| 谁维护 | 设计 / 运营 | 版师 |
| 改一次的代价 | 换个配色,几乎为零 | 要重新推档、重新打样 |
| 在这个系统里 | `product` / `category` 表 | 本文件 → `pattern` 表 |

**一个版型可以出很多款式**(同一套马面裙版型,换面料换绣样就是不同商品);
**一个款式也可能要改版**(客户体型超出档差范围)。所以是多对多,不能合成一张表。

> 红领 / 酷特智能的四大库(版型、工艺、款式、BOM)就是这么分的。
> 他们积累了两百多万套版型数据 —— **版型库是定制企业真正的资产**,
> 因为款式可以抄,版型抄不走。

## 四、档差规则(其余尺码由此推出)

推档就是从基码算别的码。**不把每个码都手写下来**,理由和相容矩阵一样:
写下来的表改一处只对一处,写下来的规则改一处对全部。

| 部位 | 每升一码 | 说明 |
|---|---|---|
| 胸围 | +4 | 行业通用档差 |
| 腰围 | +4 | |
| 臀围 | +4 | |
| 裙腰围 | +4 | |
| 肩宽 | +1 | 汉服连肩袖,肩宽档差小 |
| 领围 | +1 | |
| 通袖长 | +4 | 身高带来的臂展变化 |
| 衣长 | +2 | |
| 上襦衣长 | +1.5 | 短款,档差比长衣小 |
| 裙长 | +2 | |
| 裤长 | +3 | |
| 马面宽 | +2 | |

尺码序号:S=−1,M=0,L=+1,XL=+2(以 M 为 0)。
某码的尺寸 = 基码值 + 档差 × 序号。

### 一条特例,写下来免得每次重想

**马面裙的腰围不按档差推。** 08 号文件里说过,马面裙的褶位是从腰围反推排布的,
腰围变了褶位要重排,不是简单加 4cm —— 所以 PT04 / PT05 的腰围档差记 `+4` 只是**下单参考**,
真正出货必须由版师按实际腰围重排褶位。

> 这就是为什么马面裙的改版难度标「极高」:
> **它没有「放缝头改一下」这条退路。**

## 五、量体值 → 推荐尺码

有了尺码表,量体记录就能自动比对。判断线沿用 `08-量体与版型.md`:

| 关键尺寸与最接近尺码的差 | 结论 |
|---|---|
| ≤ 2cm | **标准码** |
| 2–5cm | **调号** —— 在标准版上微调几个尺寸 |
| > 5cm,或有体型特征 | **全定制** —— 出专属版 |

「关键尺寸」按形制取,见 08 号文件第二节。比的是**成衣尺寸减去放松量**后与人体的差,
这一步系统只能给建议,**最终由版师定** —— 系统的价值是让顾问别再凭感觉推全定制。

## 六、放松量与量体项映射

要拿客户的量体值和尺码表比,先得解决一个问题:**两张表量的不是同一个东西。**

- 尺码表里是**成衣尺寸** —— 衣服摊平量出来的
- 量体记录里是**人体净尺寸** —— 人身上量出来的

差的那部分叫**放松量**。汉服的放松量比西式大得多(宽袍大袖是形制要求,不是版型偷懒),
所以直接拿两个数相减去判断合不合身,一定判错。

### 放松量表

`围度类`要减放松量才能和人体比;`长度类`客户量的就是「想要多长」,直接比。

| 部位 | 类型 | 放松量(cm) | 对应量体项 | 说明 |
|---|---|---|---|---|
| 胸围 | 围度 | 16 | 胸围 | 汉服上衣宽松,放松量远大于西式的 8–10 |
| 腰围 | 围度 | 2 | 腰围 | 裙腰基本贴合,靠系带调 |
| 臀围 | 围度 | 8 | 臀围 | |
| 领围 | 围度 | 2 | 领围 | 立领,±1cm 就影响舒适 |
| 裙腰围 | 围度 | 18 | 腰围 | 系带可调,给足余量 |
| 肩宽 | 长度 | 2 | 肩宽 | 连肩袖,容差大 |
| 通袖长 | 长度 | 0 | 通袖长 | |
| 衣长 | 长度 | 0 | 衣长 | |
| 裙长 | 长度 | 0 | 裙长 | |
| 裤长 | 长度 | 0 | 裤长 | |
| 上襦衣长 | — | — | — | **不比对**:客户说的「衣长」通常指整体,和上襦长度不是一回事 |
| 马面宽 | — | — | — | **不比对**:马面宽不是人体尺寸,没有对应量体项 |

### 一处形制特例

**齐胸襦裙(XZ01)的「裙腰围」对应的是「胸上围」,不是腰围** ——
齐胸的裙头系在胸部上方,拿腰围去比会差十几厘米,判成「全定制」。

这正是 `08-量体与版型.md` 里说「胸上围是齐胸类退货主因、必须单独量」的原因:
**它不是多量一项,它是这一类形制唯一正确的比对基准。**

### 为什么放松量写在版型库里,而不是每次现算

放松量是版师的手艺,会随版型迭代变;但它一旦定下来,**每一次推荐尺码都要用同一套数**。
写在这里的意思是:改放松量要走改知识库的流程,**不是谁在代码里改个数就生效**。
