# 物料与 BOM

⚠️ 本文件为 `demo` 演示数据,**单价与损耗率须由采购和生产确认后替换**。

## 零、BOM 是什么

**BOM = Bill of Materials,物料清单。** 一句话:**做出这一件,要用哪些东西、各用多少。**

相容矩阵回答的是「**能不能做**」,BOM 回答的是「**要用多少料、花多少钱、几天能备齐**」。
这是定制业务的另一半 —— 现在系统里每件商品都有售价,但**说不出这个价是怎么来的**。

一份完整的 BOM 至少包含:

| 要素 | 例子 | 少了它会怎样 |
|---|---|---|
| 物料是什么 | 香云纱 / 真丝里布 / 手工盘扣 | 采购不知道买啥 |
| 规格 | 幅宽 114cm / 6 号线 | 买回来用不了 |
| **用量** | 3.6 米 / 5 对 | **算不出成本,也算不出要备多少** |
| 单位 | 米 / 对 / 克 | 3.6 到底是米还是尺 |
| **损耗率** | 满纹面料对花损耗 15% | 按净用量采购,一定不够 |
| 单价 | 380 元/米 | 报价靠拍脑袋 |
| 备料周期 | 云锦 15–30 天 | 承诺了做不到的交期 |

其中**损耗率是最容易被忽略、又最容易出事的一项**。
排料时裁片之间必然有边角浪费;满纹面料还要**对花**,损耗会翻倍。
按净用量下采购单,结果就是裁到一半发现布不够 —— 而这时候面料可能已经断货了。

### 定制的 BOM 和成衣的 BOM 不一样

成衣的 BOM 是**固定的**:这款衬衫就用这些料,存一份就行。
定制的 BOM 是**算出来的**:

```
一件的物料 = 版型的基础用料(随尺码变)
           + 所选面料(用量由版型定,损耗由面料定)
           + 所选每项工艺的附加用料
           + 包装
```

所以这个文件不存清单,存**算清单的规则** —— 和相容矩阵、和推档是同一个做法。

## 五、算料与算钱的规则

### 1. 主面料用量

```
净用量 = 版型基础用布 + 每档 × 尺码序号
幅宽折算 = 净用量 × (114 / 实际幅宽)      ← 版型的基础用布按 114cm 标定
实际采购量 = 幅宽折算 × (1 + 该面料损耗率)
```

> 幅宽折算是个**容易被跳过、跳过就出事**的步骤。
> 云锦幅宽 75cm,做同一件马面裙要用 `3.6 × 114/75 = 5.47` 米,
> 比按 114cm 算的多出 52% —— **只算差价不算多用的米数,报价会低估一大截。**

### 2. 辅料与工艺附加

```
实际用量 = (基础用量 + 每档 × 尺码序号) × (1 + 该物料损耗率)
```

### 3. 物料成本

```
物料成本 = Σ (实际用量 × 单价)
```

### 4. 这个数不是售价

物料成本只是成本的一部分。**没算进去的**:工时(见 `07-工期与成本.md` 的工日)、
版房分摊、门店与顾问成本、退换损耗、税。

> 报价 = 物料成本 × 系数,系数由财务定,**不写在知识库里** ——
> 因为它是商业机密和定价策略,不是工艺知识。
> 知识库负责让「物料成本」这个数**算得出、说得清、追得到每一项**;
> 从成本到售价那一步是另一个部门的事。
