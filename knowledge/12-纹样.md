# 纹样

「纹样」是衣服上那些花 —— 织进去的、绣上去的、染出来的。它和面料、工艺是三件事:
**面料决定布长什么样,工艺决定花怎么上去,纹样决定上的是什么花。**
同一匹云锦可以织缠枝也可以织团花;同一手苏绣可以绣折枝也可以绣宝相花。

> **来源说明**:本文属通识性整理,`demo`。**只有一条能溯到本仓库已有的知识**
> (蜀锦那条,见下),其余是行业通行说法,**未核到考古报告或馆藏编号**。
> 对客户表述时避免「据某某文物」这类需要举证的措辞。
> 补子涉及品级制度的部分**不给默认值**,必须人工确认 —— 见文末。

## 词表(十二个)

| 纹样 | 长什么样 | 常见载体 | 客户常用的说法 |
|---|---|---|---|
| 云纹 | 如意头连缀成的云,带尾 | 襕边、袖缘、织金 | 「祥云」「如意」 |
| 团花 | 圆形适合纹样,团内填花 | 蜀锦、缂丝、圆领袍胸背 | 「圆花」「团窠」 |
| 缠枝 | 枝蔓连绵不断,花叶相生 | 云锦、妆花、织金满地 | 「缠枝莲」「连枝花」 |
| 折枝 | 截取一枝,不连续 | 刺绣定位、马面裙膝襕 | 「一枝花」 |
| 宝相花 | 多层花瓣放射对称的理想化花形 | 重工刺绣、礼服 | 「大花」 |
| 回纹 | 直线折成的连续方格边饰 | 缘边、底襕 | 「万字边」「方胜边」 |
| 龟甲 | 六边形连续骨架,格内填小花 | 蜀锦 | 「六角格」 |
| 联珠 | 圆珠串成环,环内置主纹 | 蜀锦、唐风 | 「珠圈」 |
| 柿蒂 | 四瓣对称,置于领口肩部 | 领抹、肩襕 | 「四合」 |
| 海水江崖 | 下摆一圈水波加山石 | 礼服下摆、蟒袍 | 「水脚」 |
| 暗花 | 同色提花,靠光泽差显形 | 提花暗纹缎、漳缎 | 「低调的花」「同色花」 |
| 无纹样 | 素面,没有花 | 素缎、棉麻、亚麻、绫 | 「纯色」「素的」 |

⚠️ **「无纹样」是一个值,不是空着。**
素缎长衫的纹样是「无」—— 这是确定的答案;织金缎马面裙还没定 —— 这是待办。
**两者留空的话长得一模一样**,以后统计会把它们加在一起,而那个数是错的。

## 面料推常见纹样

织花的布,花是织进去的,所以**面料一定程度上决定了纹样的范围**。

| 面料 | 常见纹样 | 依据 |
|---|---|---|
| 蜀锦 | 团花、龟甲、联珠 | `02-面料.md`「经线起花,配色明丽,**纹样多见团花、龟甲、联珠**」 |
| 云锦 / 妆花 | 缠枝、宝相花、团花 | 通识 `demo` |
| 宋锦 | 折枝、回纹、龟甲 | 通识 `demo`(配色沉静,纹样典雅) |
| 织金缎 | 缠枝、云纹 | 通识 `demo`(金线满地或走襕) |
| 提花暗纹缎 / 漳缎 | 暗花 | `02-面料.md`「同色经纬提花,**纹样靠光泽差显现**」 |
| 缂丝 | 团花、折枝 | 通识 `demo`(通经断纬,适合独立纹样) |
| 素缎 / 棉麻 / 亚麻 / 绫 / 电力纺 / 绡 / 罗 | 无纹样 | 素织,花要另外绣或染上去 |

## 工艺推常见纹样

| 工艺 | 常见纹样 | 说明 |
|---|---|---|
| 各路刺绣(苏 / 湘 / 粤 / 蜀 / 汴 / 京 / 顾 / 发绣) | 折枝、缠枝 | 绣是**定位**的,多为折枝 |
| 盘金绣 / 打籽绣 | 跟随底纹 | 它们是针法,不自带纹样 |

| 蓝印花布 / 蜡染 / 扎染 / 夹缬 | 几何或晕散,**不是具象花** | `03-工艺.md`:扎染「纹样有自然晕圈,**每一件都不同**」 |
| 补子 | **不给默认值** | 见下 |

## 补子:唯一不许猜的一格

`04-配饰.md` 写着:**纹样有品级制度,用错等同于礼制错误**。
补子上织绣什么(文官飞禽、武官走兽,按品级分)不是审美选择,**是身份声明**。

所以规则是:**带补子的款,纹样留「待业务核」,不按面料或工艺推**。
推一个「缠枝」上去,图看着没问题、数据看着完整,而它说的是一件错的事。

## 本期在用 / 为扩展预留

词表十二个,但库里现在**不是每个都有**。所以每个词带一个标记:

| 标记 | 词 | 命中 0 意味着 |
|---|---|---|
| 本期在用 | 云纹、团花、缠枝、折枝、联珠、暗花、无纹样 | **故障** —— 规则坏了 |
| 为扩展预留 | 宝相花、回纹、龟甲、海水江崖、柿蒂 | 正常 —— 库里本来就没有 |

⚠️ **「一个都没抽到」有两种原因,而它们在数据上长得一模一样**:库里真没有,和抽取规则坏了。
标了之后,在用的词命中 0 就是故障(`knowledge/motif.py` 扫库时会红)。
(这个做法来自负责「场合」那条线的会话,两边用同一套。)

## 从商品名抽纹样,假阳性一抓一把

实测:292 个商品名里**真正点明纹样的只有 14 个(4.8%)**,而看着像纹样的词一大堆:

| 看着像 | 其实是 |
|---|---|
| 织金、妆花、缂丝 | **工艺** —— 怎么把花做上去,不是什么花 |
| 竹节棉的「竹」 | **面料名** |
| 襕(双襕、襕边) | **形制部件** —— 衣服上的一条带子 |
| 云肩 | **配饰** |
| 「照水」「霜序」「山鸣」 | **雅名** |

⚠️ 真栽过一次:**「盘金绣 云肩(四合如意)」被抽成了柿蒂纹** ——
四合如意说的是**云肩本身的形制**(四片式),不是它上面绣的花。
所以规则是:**只认词表里的写法,词表之外一律不认**;
宁可留「待业务核」,也不要推出一个像模像样的错词 —— 错词不会报错,它看起来就是个正经答案。

## 这份词表怎么用

`knowledge/motif.py` 把上面两张表变成可执行的推导,每条结果都带来源:

| 来源 | 意思 | 可信度 |
|---|---|---|
| `商品名` | 商品名里明写了,附上抽自哪一段 | 高 |
| `面料推导` / `工艺推导` | 按上表推的默认值 | 估算,业务可改 |
| `素面料` | 这块料本来就不织花 | 高 |
| `待业务核` | 补子这类不许猜的 | 未定 |

**业务改过的不许被重新推的覆盖** —— 和裁片用料占比那套(估算 / 复核 / 版师 / BOM)同一条规矩:
一个被人改过的数,必须查得到是谁改的、凭什么。
