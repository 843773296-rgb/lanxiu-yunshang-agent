## 一、让价边界 `业务 2026-09-24 定`

**不让价,只让东西。** 价格不动 —— 助手**不许跟顾客谈折扣、不许暗示可以便宜**,
顾客问「能便宜点吗」时,谈的是能多给什么,不是少收多少。

| 能让的 | 边界 | 备注 |
|---|---|---|
| **免首次改衣** | **只管尺寸微调**,签收后 **3 个月内一次** | 改款式、换面料不算;超过一次或超时按原价 |
| **送专业保养一次** | 缂丝、妆花这类本来就不建议客户自己洗的 | 成本是工时,不碰价格 |
| **免运费 / 免转寄** | 转寄那一支本来就要快递 | 金额小、好给;对高客单客户没有分量 |

**不能让的**:价格本身;送小件(荷包、香囊这类)**业务没选**,不许提。

### 「不让价」不只是不说折扣 `业务 2026-09-25 定`

09-25 量过一次:闸原来只认**说出口的**折扣词,10 句不带折扣词的让价话**一条没拦住**。
所以这条规矩要说清 —— 下面这几句**一样算让价**,尽管一个折扣词都没有:

| 说不得的 | 为什么 |
|---|---|
| 「我帮您跟店长**申请**一下这个价格」 | 顾客会等一个回话,而回话只能是「不行」—— 等于先给希望再收回去 |
| 「我去**问问领导**,看能不能给您争取点什么」 | 同上。价格不是可申请的事项 |
| 「这个数我**做不了主**」「后面还**有空间**」 | 都在暗示再谈能更便宜 |
| 「**月底可能有活动**」「过节应该有优惠」 | 等于让顾客现在别买;而且系统里**没有任何在办活动的依据**,这话查无出处 |
| 「走**内部价**」「按**成本价**给您」 | 名字里就写着让价 |

### 有一条不算让价:换配置 `业务 2026-09-25 定`

**换成现货面料、或者把工艺简化一些 —— 这不算让价**,因为换的是**一件不同的东西**,
价钱不同是应该的,不是同一件少收钱。
⚠️ **但不主动往低配引**:只有顾客**明确说了预算有限**,才提这一条。
(理由:顾问一旦把它当成最省力的成交路径,高客单的方案就会提得越来越少。)

**能说的那一句是**:价格不能让 → 能让的是免首次改衣 / 送一次保养 / 免运费 →
再把查得到的事实摆出来(用了多少料、多少工日、谁量的体、出问题谁负责)。

⚠️ **提「申请」不是一律不行,看申请的是什么**:
「我帮您问问店长**能不能免一次改衣**」可以说 —— 免改衣本来就是能让的三样之一;
「我帮您**问问货期**能不能提前」也可以说 —— 跟钱无关。
**分界线在那句话里有没有提到价格。**

⚠️ **「免首次改衣」和公差判责有交叉,交叉处按这条划**:
**本来就是我们做错的(超出公差、该试没试、记录不全且在 6 个月内),一律免费,不占这个名额**;
**在公差内、顾客自己想改**的那一类,本来收费 —— 这一次免,记作用掉了名额。

## 二、价格怎么构成(讲价值时的事实)`出处:07-工期与成本.md 第五节`

| 项 | 占比 | 为什么会差这么多 |
|---|---|---|
| 面料 | 25–45% | 棉麻和云锦差 20 倍以上 |
| 工艺(绣 / 织) | 20–50% | **重工款这一项可以超过面料** |
| 版型与缝制 | 15–25% | 手工 vs 机缝 |
| 配饰 | 0–30% | 全看加购 |
| 包装物流质检 | 5–10% | |

**能对客户说的硬事实**(每一条都查得到,不是形容词):
- 这一件用了哪几种料、每种多少米 —— 系统里按件算得出来(BOM)
- 这一件的工艺要多少**工日** —— 比如缂丝 15–25 工日、妆花 30–50 工日,
  **一台织机只能一个人织,加人无效**(出处:07 第三节)
- 工时怎么折钱:普通工序 300 元/工日、非遗级 800 元/工日(`业务 2026-09-24 定`)

### 我们家怎么说 · 「为什么这么贵」 `demo`

- **先讲人,再讲料,最后讲钱怎么来的。** 顾客嫌贵时,心里想的多半是「凭什么」,
  而汉服定制里最说得清「凭什么」的是**这一件要几个人做多少天** —— 料的差价顾客能在网上比,工日比不了。
- **报数,不报形容词**:工日数、用料米数从工具现查,查不到就不报,**不许说「大概要一个月工」**。
- **工时单价不主动报**。300 / 800 元一工日是成本口径,报出来顾客会拿去乘,
  然后和售价对不上(售价还含料、版、损耗、售后)—— 只在顾客追问「人工值多少」时说。
- **说到「这件为什么比那件贵」时,指出差在哪一项**(比如差在缂丝那一块),不笼统说「工艺复杂」。
- 示例(思路,不是台词):「这件贵主要贵在领缘那一圈缂丝 —— 一台机一个人,要织 X 个工日,
  加人也快不了。料是 X 米真丝,数我可以给您看。」

## 三、工期为什么这么长 `出处:07-工期与成本.md;工期推算 knowledge/lead.py`

- 工期是**算出来的**,不是拍的:按这一件的版型、面料、工艺、尺码逐项累加,
  助手答「什么时候能拿到」时**一定会去查**,不会现编
- **加钱也快不了的那几种**:织造类(缂丝、妆花)一台机一个人;
  染色类(草木染、扎染、晒莨)靠**日历天**浸染晾晒,加人无效
- 重工款的门槛:25 天 / 12 天(`业务 2026-09-22 确认`)
- 赶不上用件日期时,系统**直接拦下**并给最晚下单日,不让先下单再说

### 我们家怎么说 · 「工期能不能快点」 `demo`

- **先问用件日期,再报工期。** 顾客催,多半是有个日子(婚礼、毕业照、拍摄);
  先拿日期去算,算得出来就说「赶得上」,赶不上直接说最晚下单日已经过了,**不先应下来**。
- **说清楚是哪一道工序卡住的**:织造、染色这两类加人无效,直接说「这一道快不了」;
  缝制可以排期往前挪的,**由店长定**,顾问只说「我帮您问问排期」(**不提钱**)。
- **赶不上时给真选项**:换掉卡工期的那道工艺、或换现货面料 —— 这算换配置,不算让价;
  但**顾客没说要换,不主动劝换**。
- 示例:「您是 X 号要穿对吧?我先按这件的工艺算一下……这件卡在晒莨那道,要靠日晒,
  加人没用。赶 X 号的话,能换的是那块面料,别的我不建议动。」

## 四、「别家更便宜」怎么接 —— 比较口径

**我们不比价,比的是能说清的四件事**(这四件系统里都查得到,别家多半给不出):

1. **这一件用的什么料、多少米** —— 报得出具体数,不是「高档面料」
2. **谁量的体、什么时候量的、条件记了没有**(内搭 / 鞋 / 呼吸状态)
3. **出了问题谁负责** —— 判定表逐行有来路,公差写进合同(领围 ±1cm、胸腰 ±1.5cm、长度 ±2cm)
4. **签收要顾客本人确认试穿合身**(6 位码核验),不是店员说了算

### 我们家怎么说 · 「别家更便宜」 `demo`

- **先认,不争。** 「确实,同样的款别家能做到更低,这个我不跟您比价」—— 一争价格就落到对方的主场。
- **把比较拉回四件事,而且拿这一件的真数说**:这件用的什么料多少米、谁量的体、
  出问题谁负责(公差写进合同)、签收要您本人确认。**别家怎么做我们不评价** —— 只说自己这边查得到的。
- **请顾客拿这四条去问别家**,而不是我们替顾客下结论「别家肯定做不到」。
- **不贬低同行** —— 底线,一个字都不说别家的料、工、人。
- 示例:「价格我不跟您比。您要是去别家看,可以问问这四件:用的什么料、几米;谁给您量的体;
  做出来不合身谁负责、写不写进合同;签收是不是您自己确认。这几样我这边都能拿出来给您看。」

## 五、几条底线(助手层面已经拦住,顾问也要知道)

| 底线 | 为什么 | 谁在守 |
|---|---|---|
| 不承诺工期以外的加急 | 织造和染色加人无效,承诺了做不到 | 工期推算 + 提示词 |
| 不替顾客确认「合身」 | 签收是责任转移点,要顾客本人输码 | 状态机上的闸 |
| 不编快递单号、不编试穿码 | 编出来的号查无此单 | 写入前的闸(2026-09-24 加) |
| 不直接对客户承诺判责结果 | 判责由店长定,顾问只给建议 | 判责口径 + 提示词 |
| 不谈折扣 | 业务 09-24:不让价,只让东西 | 见第一节 |
| **不把价格推给别人或推到以后** | 业务 09-25:「我帮您申请」「月底有活动」一样算让价 | 同一道闸的第二、三层 |

## 六、顾客说「再想想」 `demo`

### 我们家怎么说 · 跟进节奏 `demo`

- **当天不追。** 顾客说再想想,当场再推一句只会把「想想」变成「不要了」。
  当场能做的只有一件事:**把这次的方案存下来**,告诉顾客回头随时能接着看。
- **第 3 天:发一条带新信息的消息**(料样照片、这件的工期算出来了、量体数据整理好了)。
  **没有新信息就不发** —— 「您考虑得怎么样了」是催,不是跟进。
- **第 7 天:只问一件事 —— 用件日期变没变。** 有日期的顾客,最晚下单日是算得出来的;
  离最晚下单日不到 7 天时,**照实说一次**「再晚就赶不上 X 号了」,这是事实不是逼单。
- **两次没回就停,不发第三次。** 进回访名单,等顾客自己回来。
- 示例(第 3 天):「X 女士,上次那件褙子的领缘工期我帮您算出来了,赶您 X 号没问题;
  料样照片也拍了,您方便时看看。」

## 七、不能说的话 `demo`

### 我们家怎么说 · 除了「不贬低同行」之外 `demo`

| 不能说 | 为什么 |
|---|---|
| 「这是**最后一件** / 料**快没了**」(查不到库存依据时) | 编出来的稀缺;库存工具查得到就照实说,查不到不许说 |
| 「**今天定**的话……」 | 等于暗示过了今天条件会变,而我们不让价,条件本来就不会变 |
| 「**保证**不会出问题」「**一定**合身」 | 合身由顾客签收确认,出了问题按公差判 —— 不许提前许诺结论 |
| 「这个**明星 / 博主**也穿」 | 查无出处,而且把选择推给了别人 |
| 「**非遗传承人**亲手做的」(工单上不是时) | 工艺有「非遗」字段不等于这一件是传承人做的,要查得到是谁做的才说 |
