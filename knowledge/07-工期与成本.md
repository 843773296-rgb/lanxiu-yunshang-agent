# 工期与成本

⚠️ **全部为量级参考,不是报价单。** 标 `scale` 的是公开资料里的行业量级,
标 `demo` 的是为跑通流程虚构。**真实项目必须以本企业实际产能与成本核算替换。**

这份文件要解决的是一个具体场景:
> 客户问「这个大概多久能拿到、大概多少钱」,顾问要能当场给出**一个区间和一句理由**,
> 而不是「我问一下再回复您」。

---

## 一、为什么定制说不清工期

定制的工期不是各环节相加,而是**几条并行的链路里最长的那条**。

```
面料备料 ──┐
           ├─→ 裁剪 ─→ 缝制 ─→ 整烫 ─→ 质检 ─→ 交付
绣片制作 ──┘         (绣片需在缝制前完成)

配饰制作 ────────────────────────────┘(可并行,可后补)
```

关键结论:
- **面料备料和绣片制作是并行的** —— 加起来算工期是常见的高估
- **绣片必须在缝制前完成** —— 所以重工绣片是真正的瓶颈
- **配饰可以并行也可以后补** —— 不应计入主服工期

| 宋锦 | 10–20 天 | |
| 云锦 | 15–30 天 | 手工织造,难加急 |
| 织金缎 | 10–25 天 | 金线含量影响 |

> 这条要在下单时告知,而不是延期时才解释。

## 三、工艺工日 `scale` / `demo`

「工日」= 一个师傅做一天。**不等于日历天** —— 两个师傅并行,10 工日约 5 天。

但**有些工序的时间除不动**:

- **织造类**(缂丝、妆花):一台织机只能一个人织,加人也没用
- **染色类**(草木染、扎染、蜡染、晒莨):浸染和晾晒是**日历天**,不是工日,加人无效
- **一人一稿类**(手绘、顾绣、发绣):换人笔触就变,分工等于毁了这件

## 四、整单工期估算 `demo`

```
整单工期 ≈ max(面料备料, 绣片工日 ÷ 并行师傅数) + 缝制 + 整烫质检 + 物流
                                                    5–10天    2–3天    2–5天
```

### 三档典型

| 档位 | 典型配置 | 工期 | 说明 |
|---|---|---|---|
| **快** | 现货面料 + 平绣局部 + 机缝 | **15–25 天** | 预算款、赶场次 |
| **中** | 宋锦/绫 + 苏绣局部 + 手工锁边 | **35–50 天** | 主力档 |
| **重** | 云锦/缂丝 + 重工绣 + 全手工 | **90–150 天** | 婚服、收藏级 |

> **婚礼订单必须倒推。** 客户说「10 月办婚礼」,重工档要 5 月就下单。
> 这条要做成系统提醒:**下单日 + 预估工期 > 用件日期时,直接拦截并提示改配置。**

## 五、成本构成 `demo`

| 项 | 占比 | 波动来源 |
|---|---|---|
| 面料 | 25–45% | 面料档次差异极大(棉麻 vs 云锦差 20 倍以上) |
| 工艺(绣/织) | 20–50% | **重工款这一项可以超过面料** |
| 版型与缝制 | 15–25% | 手工 vs 机缝 |
| 配饰 | 0–30% | 全看加购 |
| 其他(包装物流质检) | 5–10% | |

### 给顾问的报价话术

> 「价格主要看两件事:**面料档次**和**工艺量**。
> 同一个款,用醋酸配平绣,和用云锦配缂丝,差价可以到十倍以上。
> 您先告诉我预算区间,我给您配一套里面最好的方案。」

**先问预算再配方案,不要先配方案再报价** —— 后者是定制成交率最大的杀手。

## 六、加急 `demo`

| 加急方式 | 能压缩多少 | 代价 |
|---|---|---|
| 改用现货面料 | 备料 10–25 天 → 1–3 天 | 面料选择大幅受限 |
| 增加绣工并行 | 绣片工期 ÷ N | 成本上升,**且多人绣同一件会有针法差异** |
| 简化工艺 | 视情况 | 需客户确认降配 |
| 机缝替代手工 | 缝制 2–4 天 | 「高定感」下降 |

> **不能压缩的:** 织造类(缂丝、妆花、织金)—— 手工织机的速度是物理上限,
> 加人也没用,因为一台织机只能一个人织。
> 这是「加急要求」必须当场拒绝的唯一一类,**其余都可以谈**。
