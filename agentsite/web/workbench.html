让智能体现场做一道题

后台每天堆着两类人做的活:退款失败转人工和疑似重复客户待合并。 这两类都不能提前把步骤写死 —— 查完押金才知道要不要查流水,看完流水才知道要不要查客户。
循环、上下文、工具调度全由 Claude Agent SDK 管,工具经 MCP 挂载; 标注答案与判分留在后台,本站只跑智能体。
