# 定制报价单

## 什么时候用

顾问要给客户一份**能发出去的东西**时用。判断标准:这份东西会被转发给客户看。

不是每次问价都要出报价单 —— 客户随口问「大概多少钱」,直接答区间就行。
**只有要落到纸面上、会被转发的,才走这个流程。**

## 为什么要固定格式

报价单是**会被截图转发**的东西。顾问发出去之后,它会脱离对话上下文独自存在:
客户转给家人看、隔三个月再翻出来问「你们当时说 xx 的」。

所以每一份都必须**自带完整前提**:哪些是确认的、哪些还要评估、这个价含什么不含什么、
工期从哪天算。少一句,三个月后就是一场纠纷。

**免责声明不是免责,是把前提说清楚。** 前提说清楚了,后面才谈得下去。

---

## 第一步:先查,再写

出报价单前必须查完这五样,**一样都不能省**。缺哪样就去问顾问要,不要自己填。

| 查什么 | 用什么工具 | 缺了会怎样 |
|---|---|---|
| 工艺 × 面料能不能做 | `kb_combo` | 承诺了做不出来的东西 |
| 客户穿哪个码 | `kb_fit`(要客户号)或问顾问 | 报了价却做不合身 |
| 要用多少料、物料成本 | `kb_bom` | 价格是编的 |
| 多久能拿到 | `kb_lead`,有用件日期就传 `need_date` | 交期是编的 |
| 面料有没有现货 | `get_stock` | 说不清能不能加急 |

**`scope` 参数要问清楚**:客户说的是局部还是整幅?整幅是局部的 4 倍,
这一个参数错了,成本和工期同时错四倍。

## 第二步:按这八段写

### 1 · 方案
形制 / 版型 / 尺码 / 面料 / 工艺 / 颜色 —— 逐项列出,一项不省。
标 `demo` 或 `scale` 的项要在这里就打上标记。

### 2 · 可行性
把 `kb_combo` 的结论原样写出来,**带上依据**(规则号或「人工确认」)。

- 「可」→ 正常往下
- 「需评估」→ **必须写明:未经工艺负责人确认前,本方案不构成承诺**
- 「不可」→ 不出报价单,直接说做不了并给替代方案

### 3 · 尺码
`kb_fit` 的档位(标准码 / 调号 / 全定制)+ 判定理由 + 关键尺寸差值。

档位是「需补量」时:**写明还要量哪几项,不要给推荐码。**
系统比不了的关键尺寸(如马面宽)要单独列出来说「须版师确认」。

### 4 · 用料
`kb_bom` 的逐项清单:物料 / 净用量 / 损耗率 / 实际用量 / 单价 / 金额。
**损耗那一列不要删** —— 客户看到「3.6 米的料要买 4.2 米」才理解为什么贵。

### 5 · 价格
写**物料成本**,以及它占整体的比例区间(面料 25–45%、工艺 20–50%,见工期与成本文件)。

> **助手不给最终售价。** 物料成本 × 系数才是售价,系数由财务和店长定,
> 那是定价策略不是工艺知识。这里只负责把成本说清楚、追得到每一项。

写成:「物料成本 ¥X(逐项见上),最终报价由店长按定价系数出。」

### 6 · 工期
`kb_lead` 的**区间**,并注明**对外按最慢那个数**。要写:

- 关键路径卡在哪一环(备料 / 绣织 / 印染)
- 不能靠加人压缩的工序要点名(织造、染色晾晒、手绘顾绣发绣)
- 有用件日期的,写最晚下单日
- 天气相关的(香云纱晒莨)必须单独提示

### 7 · 前提与有效期
- 面料现货状态(有现货 / 需备料 N 天),以及**现货是会被别的单占掉的**
- 报价有效期(面料价格会波动,建议 15 天)
- 换料的影响:质感和售价都会变,**必须客户确认,不能替他决定**

### 8 · 免责声明

下面这几条,**该出现的一条都不能少**。判断标准:方案里有这个情况,就必须有这句话。

| 什么情况 | 必须写的话 |
|---|---|
| 任何报价单 | 「本单所列为**物料成本**,不含工时、版房分摊、门店成本与税,**不是最终报价**。」 |
| 任何报价单 | 「工期为**区间估算**,以最慢值为准;受面料备料与产能排期影响。」 |
| 有 `demo` / `scale` 数据 | 「本单部分数据为演示/行业参考值,**须经工艺负责人确认**后方可对外承诺。」 |
| 相容矩阵判「需评估」 | 「该工艺与面料组合需打样评估,**评估通过前本方案不构成承诺**。」 |
| 用到香云纱 / 晒莨 | 「香云纱晒莨需日照,**雨季可能延期**,交期需留余量。」 |
| 尺码档位是「需补量」 | 「尺码尚未确定,**需补量后方可开工**;本单价格按参考尺码估算。」 |
| 有手绘 / 天然肌理面料 | 「手工绘制与天然肌理**每件不同,不可完全复制**,以打样为准。」 |
| 客户可能换料 | 「更换面料将同时改变质感与价格,**须客户书面确认**。」 |

## 常见错误

**把物料成本当报价发出去。** 这是最贵的一个错 —— 客户会拿着这个数字来对账,
而真实售价是它的两三倍,解释起来像是临时加价。

**只报最快工期。** 「最快 95 天」发出去,客户记住的就是 95 天。**报最慢那个。**

**「需评估」写成「可以做」。** 需评估是「还不知道」,不是「可以」。
写成可以做,等于替工艺负责人做了决定。

**替客户决定换料。** 「我给您换成素缎,便宜还快」—— 质感变了,这是客户的钱和客户的婚礼,
只能给选项,不能替他选。

**省掉损耗那一列。** 客户看不到损耗,就理解不了为什么 3.6 米的裙子要买 4.2 米的料,
只会觉得在多收钱。

---

## 一句话总结

**报价单是会被转发的东西,所以它必须自带前提。**
查全五样、写全八段、该有的免责一条不漏 —— 剩下的交给店长定价。
